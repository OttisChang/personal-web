# 🧑‍💻 Personal Portfolio & Resume

這是一個使用現代化技術建構的個人網站與數位履歷，主要用於展示前端進階實作能力與前後端架構整合。

## ✨ 核心功能 (Key Features)

*   **🌐 國際化 (i18n):** 實作多國語系，支援中/英文履歷內容無縫切換。
*   **🌓 深淺主題 (Dark/Light Mode):** 實作流暢的深淺色模式切換，提供最佳的使用者閱讀體驗。
*   **📄 動態資料管理:** 履歷資料來源統一以 JSON 格式儲存，並透過後端 API 靈活提供與維護。

## 🛠️ 技術棧 (Tech Stack)

**Frontend:**
*   React
*   Next.js
*   TypeScript

**Backend:**
*   Python
*   FastAPI
